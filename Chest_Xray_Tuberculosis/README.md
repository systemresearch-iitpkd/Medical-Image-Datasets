Contains images belonging to 2 classes: Normal and Tuberculosis. Images are organized in two folders depending on their classes as .png files. Also, details about the pictures are stored in metadata files.

Images are taken from [kaggle](https://www.kaggle.com/datasets/tawsifurrahman/tuberculosis-tb-chest-xray-dataset) and more details can be found in the [paper](https://ieeexplore.ieee.org/document/9224622)
