- Contains images belonging to 3 categories: Covid, Normal and Viral pneumonia. 
- Contains 111, 70 and 70 images belonging to covid, normal and viral pneumonia classes respectively. 
 - Images folder consists of a train and a test folder which contains images subdivided into the above 3 categories. 

- Images are taken from [kaggle](https://www.kaggle.com/datasets/pranavraikokte/covid19-image-dataset)
