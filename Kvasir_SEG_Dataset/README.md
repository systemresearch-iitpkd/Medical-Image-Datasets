Images folder contains Segmented Polyp Dataset for Computer Aided Gastrointestinal Disease Detection. The images and its corresponding masks are stored in two separate folders with the same filename.

More details can be found in [Kvasir-SEG: A Segmented Polyp Dataset](https://dl.acm.org/doi/10.1007/978-3-030-37734-2_37) paper and [Kvasir SEG](https://datasets.simula.no/kvasir-seg/)
