# Medical-Image-Datasets
- Dataset has been collected under the project funded by IHUB NTIHAC FOUNDATION titled "Securing Deep Neural Networks against Adversarial Attacks in Medical Imaging" PI Dr. Vivek Chaturvedi.
- Dataset formed by collecting images from different sources.
- Contains a list of datasets which can be used for different machine learning tasks such as classfication and segmentation.
- Details about each dataset can be found in a separate readme file inside each link.
- Source of the dataset and resources for additional information are also included in the readme files.
